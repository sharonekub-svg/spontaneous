# nadlan-scout 🏠

מערכת לאיתור עסקאות נדל"ן בישראל: קנייה מתחת למחיר השוק, שיפוץ, ומכירה או השכרה.

**העיקרון:** במקום לנחש לפי מודעות ביד2, המערכת בונה "מחיר שוק אמיתי" מכל
העסקאות שנסגרו באמת (המאגר הממשלתי של רשות המסים — nadlan.gov.il),
ואז משווה כל מודעה למחיר הזה ומריצה עליה את כל הכלכלה האמיתית:
מס רכישה, שיפוץ, מימון, תיווך, מס שבח.

## התקנה

אין מה להתקין. Python 3.10+ בלבד, בלי ספריות חיצוניות.

## איך עובדים עם זה — 4 שלבים

### שלב 1: מורידים עסקאות אמת

```bash
python3 scout.py fetch --cities "קרית גת,עפולה,באר שבע" --out data/deals.csv
```

זה מושך מהמאגר הממשלתי את כל העסקאות האחרונות בערים שבחרת.
(עד שתריץ את זה, כל הפקודות עובדות על `data/sample_deals.csv` — נתוני **דמו
מומצאים** שנוצרו ע"י `data/make_sample_data.py`, רק כדי לראות איך הכל עובד.)

### שלב 2: מדרגים ערים — איפה לחפש בכלל

```bash
python3 scout.py cities --deals data/deals.csv
```

הציון משלב: אשכול חברתי-כלכלי (עיר מבוקשת אך לא יקרה מדי), צמיחת אוכלוסייה,
ומומנטום מחירים שמחושב חי מהעסקאות. הנתונים העירוניים ב-`data/cities.csv` —
תמונת מצב שכדאי לרענן מדי שנה מאתר הלמ"ס.

### שלב 3: לומדים את מחירי השוק

```bash
python3 scout.py model --deals data/deals.csv
```

חציון ₪/מ"ר לכל עיר ושכונה + מגמה שנתית. זה מה שהופך אותך למי שיודע
תוך 30 שניות אם מודעה זולה באמת.

### שלב 4: מנתחים מודעות

ממלאים קובץ CSV עם מודעות שמצאת (ביד2, מדל"ן, פייסבוק — ידנית):

```csv
city,neighborhood,address,rooms,sqm,asking_price,condition,floor,year_built,url
קרית גת,כרמי גת,רחוב הכרמים 7,4,90,745000,ok,4,2012,https://...
```

`condition`: ‏`shabby` (מוזנח) / `ok` (סביר) / `renovated` (משופץ).
‏`floor` ו-`year_built` לא חובה — אבל אם הם שם, המודל מדייק את השווי לפיהם.

```bash
python3 scout.py analyze --deals data/deals.csv --listings data/my_listings.csv
```

הפלט: כל מודעה מדורגת 🔥 דיל / 🟡 שווה בדיקה / ❌ עזוב, עם רווח נטו צפוי
אחרי **כל** העלויות.

### שלב 5: דשבורד, התראות ואוטומציה

```bash
# דשבורד HTML עם גרפים — נפתח בכל דפדפן, בלי אינטרנט
python3 scout.py report --deals data/deals.csv --listings data/my_listings.csv

# הוספת מודעה בלי לפתוח את הקובץ
python3 scout.py add --city "קרית גת" --neighborhood "כרמי גת" \
  --address "רחוב הכרמים 7" --sqm 90 --asking-price 745000 \
  --condition ok --floor 4 --year-built 2012 --url "https://..."

# בדיקה + התראת טלגרם על כל דיל חדש (להרצה יומית ב-cron)
python3 scout.py watch --deals data/deals.csv --listings data/my_listings.csv

# עדכון נתוני אוכלוסייה מ-data.gov.il וחישוב צמיחה אמיתית בין הרצות
python3 scout.py refresh-cities
```

הגדרת טלגרם (חינם): יוצרים בוט אצל ‎@BotFather, ומגדירים משתני סביבה
`TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_ID` (הוראות מלאות ב-`nadlan_scout/alerts.py`).
בלי הגדרה, ההתראות מודפסות למסך.

להרצה יומית אוטומטית בלינוקס/מק: `crontab -e` ולהוסיף
`0 8 * * * cd /path/to/nadlan-scout && python3 scout.py watch --deals data/deals.csv --listings data/my_listings.csv`

### מודל מחיר חכם

המודל לא מסתפק בחציון לשכונה: הוא לומד מהעסקאות של כל עיר כמה
**קומה** ו**גיל בניין** מזיזים את המחיר (רגרסיה, ללא ספריות), ומתקן את
השווי לכל מודעה שיש בה `floor` ו-`year_built`. התיקון חסום ל-±15%
כדי שרעש בנתונים לא ייצר הערכות הזויות.

### בונוס: מחשבון עסקה בודדת

```bash
# פליפ: קנייה ב-900 אלף, מכירה ב-1.25 מיליון, 75 מ"ר, שיפוץ בינוני
python3 scout.py calc --buy 900000 --sell 1250000 --sqm 75 --level medium

# השכרה: קנייה ב-700 אלף, שכ"ד 3,200 ₪
python3 scout.py calc --buy 700000 --rent 3200 --sqm 65 --level light
```

## למה אין פה סקרייפר של יד2?

כי סקרייפר שרץ על כל האתרים 24/7 נחסם תוך ימים וגם מפר את תנאי השימוש
שלהם. והאמת החשובה יותר: **מחירי מבוקש הם לא מחירי שוק.** מוכרים מבקשים
מה שבא להם; עסקאות סגורות הן האמת. לכן הבסיס הוא הנתונים הממשלתיים,
ואת המודעות המעניינות אתה מזין ידנית — 10 דקות ביום, וזה גם מכריח אותך
להסתכל על השוק בעיניים ולא רק באלגוריתם.

## מה המספרים אומרים באמת (שיעור חשוב)

תריץ כמה עסקאות במחשבון ותראה משהו מפתיע: **רוב העסקאות מפסידות.**
זה לא באג. מס רכישה 8% למשקיע + מס שבח 25% + תיווך + מימון אוכלים
20-25% מכל עסקה עוד לפני השיפוץ. בגלל זה פליפ בישראל עובד רק כשקונים
**הרבה** מתחת לשוק (15%+), וזה בדיוק מה שהמערכת מחפשת.

## אזהרות כנות

- שיעורי המס בקוד (`nadlan_scout/deal_calc.py`) נכונים לתחילת 2026 —
  לוודא מול רשות המסים לפני עסקה אמיתית.
- ה-API של nadlan.gov.il אינו רשמי ומשתנה מדי פעם. אם `fetch` נשבר —
  לפתוח את האתר עם DevTools ולעדכן את `fetch_deals.py`.
- המערכת מצביעה, היא לא מחליטה. לפני עסקה אמיתית: שמאי, עו"ד מקרקעין,
  בדיקת נסח טאבו וחריגות בנייה. תמיד.
